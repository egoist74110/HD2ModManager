# IAS 安装规则与「重复 / 冲突 / 库内识别」问题记录（2026-11-26）

用户提出，待拍板后再出设计稿、派活。本文只记现状与建议，不含实现。

## 现状：IAS 怎么规定安装（已核代码）

- **官方规则只管「启用」**：角色可以装任意多个；同时**启用**的角色不能占同一件装备的 Archive（护甲、头盔各一个）。官方在 `NativeRuntimeInputs.Create` → `InspectEnabledConflicts` → `ModConflictReport.RequireClear()` 时检查，冲突则整次 regenerate 失败。见 `docs/agent/ias-module-archive-conflict-report-20261125.md`。
- **官方 IAS Mod（作者打好的主包 + 配套）**：占哪件装备由作者定死，管理器不能改。
- **我们转出来的（求生 VPK / 普通 Mod / 素体 → IAS）**：可挑底子。首选被已启用角色占用时，按候选目录（游戏里全部护甲/头盔）挑第一个空闲的；全部被占才失败（`IasVpkAllocation.Select`，`HD2ModManager/Services/Ias/IasEquipmentCatalog.cs`）。
- **W32 预检**：拖入 IAS 主包+配套、普通 Mod 转换、开启停用角色，都在导入/启用前比对启用占用；冲突直接返回「与已启用角色『X』占用同一装备（…），请先停用其中一个。」——**整次添加失败，不会装进来**。
- **重复安装**：再装同一身份的 IAS Mod，`IasModTransaction.cs:104` 抛「Mod 库中已存在同一身份：…」。
- **库内识别**：IAS 页只认 `<AppRoot>\ias\library\roles.json` 登记过的角色。库里已有的 IAS Mod（W38 前当普通 Mod 导入的 IAS 包、上一份管理器转出的角色）IAS 页看不到；后者再添加还会撞「已存在同一身份」（见 dispatch next-batch-notes「IAS 遗留角色」）。

## 问题

1. 两个 IAS Mod 替换同一件护甲：第二个直接装不进来。官方其实允许装、只是不能同时启用。
2. 「护甲被替换完了就不能装」：官方 IAS Mod 的那件护甲被占时确实装不进来；转换类只有全部候选都被占才失败（实际很难）。
3. 已装过的再装：报错，不友好；没有区分「完全相同」和「新版本」。
4. 两套 IAS Mod 抢同一件护甲时，开关上没有提示是谁占着，也没有一键「换成这个」。
5. Mod 库里已有的 IAS Mod，IAS 页应能识别，显示为「已装、未启用」。

## 建议（待用户拍板）

- A. 冲突时**照装、默认停用**：装进来，消息中心/结果提示「已装好但没启用：和『X』占同一件护甲（名字）」，附「换成这个」（停用 X、启用新的）。
- B. 重复安装：内容完全相同 → 跳过并提示「已经装过『X』」；内容不同 → 原地更新，保留启用状态和设置，提示「已更新『X』」。不弹确认（[[no-drop-confirm-dialogs]]）。
- C. 开启一个与已启用角色冲突的角色：自动停用占着的那个并提示（不弹确认），或仍拦下只提示——二选一。
- D. 角色列表标出「与『X』占同一件护甲」。
- E. IAS 页加载时扫描 Mod 库里的 IAS 包/遗留角色，未登记的显示为「库里有，未启用」，开启时补登记；合并原「IAS 遗留角色」修复。
- 涉及界面，先出可交互设计稿给用户确认再派（[[ui-design-mockup-first]]）。

## 用户决定（2026-11-26）

设计稿（第 3 版）：https://claude.ai/artifact/PH2NFiEeB8HeFEQdSKuj4Z

1. 抢同一件护甲拖入：照装、默认不启用，提示和谁抢、带「换成这个」。
2. 打开冲突角色：**自动停用占着的那个**，提示停了谁，不弹确认。
3. 再拖同一个 Mod：**有变化就原地更新**（保留启用状态/名字/设置）；**没变化不装、不弹窗，只提示，并刷新一次列表**。
4. 角色列表分两组：**「已启用」在上、「未启用」在下**；Mod 库里有但 IAS 没登记的 IAS Mod 放进「未启用」，带「库里有，未启用」标签，打开开关即登记并启用。
5. 加**刷新按钮**（标题右侧，旁边显示上次同步时间）：重扫 Mod 库与 IAS 登记，识别新出现的 IAS Mod、文件改过的角色、库里已删的角色（标「库里已删除」，不自动卸载）。自动刷新时机：打开 IAS 页、模组库导入/删除后、切回 IAS 页；后台跑、只读清单不解包。刷新不自动启用任何角色。
