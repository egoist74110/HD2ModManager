# W21 · IAS 手臂绑定对齐计划

1. 用 W18 的 Milfy 档案和只读游戏 avatar，从 Unit 读取实际绑定矩阵。两侧逐骨记录位置差、旋转差、父骨和现有名称，再决定锁骨和肩部的参与范围。
2. 扩展 IAS 专用的 W18 烘焙。保留原调色板权重、非目标槽位的单位变换和法线逆转置。覆盖整条上臂、前臂、扭转骨、手掌及全部指节。用躯干与手臂的现有混权检验肩部过渡。
3. 对同拓扑网格比较无对齐、W18 和 W21。重跑 W18 的握拳与腕口测量，增加肘、肩、90° 屈肘和 90° 抬臂。输出逐骨数据、区域指标和 PNG，回读并逐字节对照物理容器。
4. 跑 Debug 构建、六个测试项目及 Lua 回归。用最终转换产物制作 ZIP，并以 ZIP 本身跑 `hd2mod import plan`。工作产物放在 `tmp/ias-w21/`，完整报告放在 `docs/agent/`。
