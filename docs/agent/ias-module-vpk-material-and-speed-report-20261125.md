# W27 · 求生 VPK 转 IAS 的材质修复与打包计时

## 材质错配

原故障包的 11 个有可见几何的 Unit 共 172 个可见段，全部绑定到原版材质。主包同时带了 14 份转换材质和 16 张贴图，可见段引用其中 0 份。头盔和身体都出现了同一种错绑。

W23 把 IAS 的绑定依据从材质名改成 `SourceMaterialIndex`。IAS 先借普通装配器只生成材质包，再自行写 Unit，因此给 `VpkPatchAssembler` 的 Unit 计划为空。普通路径从计划里的三角面收集索引，IAS 的空计划只能得到值为 `-1` 的资源记录。IAS 丢弃这些记录后，将空绑定表交给 `UnitAuthor`，后者逐段回退到原版外壳材质。暂存版本中的材质名映射能读到 `-1` 记录，解释了同一调用此前为何有正确外观。

IAS 现在从实际输出的默认 bodygroup 和人体分区收集源材质索引，交给普通装配器生成随包材质和纹理。VPK 自带资源优先，配置了求生共享资源时可以补齐缺项。写 Unit 前检查每个源索引都有随包材质，写出后逐可见 LOD 和 section 回读，与该段的源索引比对。材质闭包及明显可诊断的普通路径灰色占位策略沿用现有转换器。

`Torso_Armor` 影响胸部几何的目标格子，`preserveAbsentCustomization` 影响 Unit 定制区。两个开关在修复前后均保持同样取值。头盔和身体在保留相同归档与 `.patch_2` 材质层的条件下恢复正确绑定，排除了材质层改名是这次错绑的原因。

## 官方 Generator 与回读

官方 1.6.4 的 `runtime_generation.py` 通过资源键 `(FileID, TypeID)` 汇总各输入归档，已部署模式按同一键调用 `resolve_mod`。实测以身体材质层同时供身体和头盔使用，两种解析模式生成相同的别名和视觉载荷。AQ SDK 生成项目私有材质及贴图 ID，并改写材质表中的贴图引用和 Unit 的材质引用。Generator 再复制 Unit 和材质，检查父材质及贴图，并保留 `0x4c567810`、`0x90b84a53`、`0xe67ac0c7` 三个 authored 槽。回读使用随 1.6.4 分发的默认材质模板及游戏中的当前父材质。

回读对每个 Unit 的 mesh 列出 LOD、源材质名、发布材质 ID 及面数。点网格和剔除网格仍沿用原版资源或空槽。依赖检查覆盖可见、点网格与剔除网格的非空 Unit 材质表引用，递归检查材质的父材质和贴图。随包贴图检查资源类型、DDS 头、BC7 DXGI 编码和 GPU 载荷尺寸。两份 ZIP 检查 CRC，补丁通过官方解码且所有非空 GPU 载荷偏移均为 64 字节对齐。

- `2606520120`，源模型 `survivor_manager`，82,764 个源三角面。11 个有可见几何的 Unit 共 172 个可见段，错绑 0。98 个依赖节点缺失 0。头盔 `ba608598be894295` 的 `hair_HakuNT` 对应 `172ca65fe1cbba7b`，脸部和衣服各自对应源材质。官方 Generator 复制 13 份材质。 [逐 Unit 回读](../../tmp/ias-w27/final-2606520120-audit.log) · [主包](../../tmp/ias-w27/final-2606520120/IAS_MainMod.zip) · [配套包](../../tmp/ias-w27/final-2606520120/IAS_Companion.hd2irpack.zip)

## 写死项清单

| 项 | 取值和来源 |
| --- | --- |
| VPK、装备归档、项目 ID、SDK 路径、Generator 版本 | 由调用参数或已安装组件提供。DP-8、两份 VPK 的路径及样本 UUID 仅用于命令和报告。 |
| 人体分区与 IAS 槽、材质补丁层 | 沿用现有 `RegionSlots` 和 `.patch_2` 输出布局。归档来自当前装备和本包实际写出的域，原版资源键来自 AQ SDK 数据表及游戏归档。 |

| BC7 格式、并行上限 | 沿用原有纹理编码和 `VpkParallel` 的核数规则及环境变量覆盖。缓存以像素内容、宽高、sRGB 区分。 |
| ZIP 压缩级别 | 新设主包 DEFLATE 级别 `1`，仅控制 ZIP 压缩。 |
| 计时协议 | 新增内部 Python 标记 `IAS_TIMING`、中文段名和毫秒单位。 |
| 审计常量 | 审计工具使用已知资源类型、二进制字段偏移、官方视觉 Package 键和官方保护槽。生产代码未引入样本专属分支。 |
