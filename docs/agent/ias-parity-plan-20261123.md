## A. 搬过来修异常（按顺序做，每步离线可验）

### A1 独立骨件：按清单追踪，不再漏件（修"手臂弹出"，#1 #3 #12 #18 #24）

现状（`physbone_runtime.lua:3755–3924`）：每 1800 帧把状态整个丢掉重扫；只收 avatar 根节点 1 m 内的件；扫不到的件这 1800 帧都不驱动，独立骨停在绑定姿势，看起来就是手臂弹出来。

改成：
1. **转换器写清单**：每件带独立骨的护甲件写进运行时选项，键是该件的 unit 资源 ID（与运行时 `unit_tag` 输出的 `#ID[…]` 同一格式），值是它应有的 `ias_*` 骨名列表。运行时据此知道"每个 avatar 应该凑齐哪几件"。
2. **重扫不丢已追踪件**：仍存活、仍有那些骨的件保留；只补找缺的件。
3. **缺件时快速补扫**：清单没凑齐时每 30 帧补扫一次（只对带肩骨名的 unit 读位置，沿用 2.1.49 的安全筛法），凑齐后才回到长周期。
4. **归属改成"离哪个 avatar 最近"**：去掉固定 1 m 门槛；件的位置取件上肩骨的世界位置，归给最近的 avatar，且距离 ≤ 2 m（宽松的安全上限，防止拿到远处无关物件）。
5. 日志：每次扫描写"清单 N 件 / 找到 M 件 / 缺哪些"；缺件持续 > 2 秒写一次警告。

### A2 每件失败隔离 + 兜底（#12 #13）

1. 每帧检查源旋转和输出四元数有限、setter 和 `update_unit` 成功。同一源骨和同一模型父骨的读数在帧内复用。
2. 连续 3 次失败进入隔离，连续 3 次健康才恢复。日常写入失败按帧计数。抽样发现的异常优先复查，每个复查帧计一次，未采样的帧保留已有判定。各件独立计数。
3. **隔离期间的兜底（§D-2 已定）**：把该件写回"抄 avatar 旋转、不做 IK"的最简姿势；连这个也失败就隐藏该件（`Unit.set_unit_visibility`），恢复时再显示。绝不让它停在绑定姿势。
4. 抽样回读：正常情况下每 30 帧轮完各件，一帧最多抽一件。大件的局部缩放检查分帧完成，最后一帧同时比对手腕世界位置。缩放任一分量超出 `1 ± 0.0001`，或腕位置偏差 > 2 cm，均记为失败。写入或回读失败时可以立即补查该件的缩放。

### A3 动作状态判定 + 握枪 IK 只在持枪时开（修"换弹诡异"，#4 #5 #6 #7）

1. 安全门：每帧先 `Unit.alive` → `Unit.has_animation_state_machine`，都过了才调 `Unit.animation_get_state`；返回长度必须是 31，否则当"未知"。
2. 分类（三种模式）：
   - **持枪**（第 11 层处于空主动作、第 4 层不是菜单状态、第 1/3 层是已知持枪/放低组合）→ IK 开；
   - **主动作**（第 11 层有动作，如换弹、投掷、互动；用 `animation_layer_info(unit, 11)` 取片段时长辅助识别）→ IK 关，只抄旋转，手跟原生轨迹走；
   - **菜单 / 未知 / 拿不到状态** → IK 关（安全默认）。
3. IK 权重在 0↔1 之间按现有 `armBlendTime`（0.12 s）平滑过渡，避免切换时手臂跳。
4. 初始状态表用 IAS 1.6.3 里的编号当假设（见盘点报告"动作状态表"），**另外加状态采集日志**：状态元组变化时写一行（层号、状态号、第 11 层片段时长）。用户实机做站立、举枪、换弹（2 种枪）、冲刺、扑倒、投弹、打开菜单各一次，据此确认或修订状态表。
5. 版本保护：开机后若 600 帧内一个已知持枪状态都没出现过（说明游戏更新改了编号），整体退回"IK 关"并写警告；其它功能照常。

### A4 骨头换算改成世界增量（#10 #11）

现状：直接抄 avatar 的 local 旋转。模型和 avatar 静止朝向不同时会累积偏差。
改成：
1. 转换器把每根独立骨的**模型静止世界旋转**和对应 **avatar 静止世界旋转**写进选项。
2. 运行时：`D = avatar 当前世界旋转 × inv(avatar 静止世界旋转)`；模型目标世界旋转 = `D × 模型静止世界旋转`；沿模型自己的父链（Lua 内计算，不额外读引擎）换成 local 再写。位置不写（骨长保持模型自己的）。
3. 四元数和上一帧取同半球（点积为负就整体取负）。
4. 引擎调用数不应增加：读 `world_rotation` 替代读 `local_rotation`，一根一次。若实测更多，报告里说明。
5. 和旧方式各留一个开关（`independentRetarget = "worldDelta" | "localCopy"`），默认新方式，便于实机对照。

### A5 IK 本身的约束（#8 的可用部分）

1. 用模型臂长；`acos` 参数夹到 [-1, 1]；可达上限 `0.99999 ×（上臂+前臂）`；最多拉伸 5%，超出就停在最远可达点，不硬拉。
2. 手腕朝向、肘极向沿用 avatar 当前肘平面（`上臂 × 前臂` 法线）；法线退化时沿用上一帧。
3. 修正作为刚体整体作用到手和全部手指（手指不散）。
4. 出现非有限数就放弃这一帧的 IK（回到只抄旋转）。
5. "把枪拉近 ≤18 cm"不在本节做：改为第 2 批的实验开关，默认关，见 §D-3。

### A6 多个 avatar（队友）都驱动（#2 #17 的本地部分；设置开关，默认关，§D-1）

现状：独立骨只驱动本地玩家。队友若也穿这个 Mod，他们的手臂件会停在绑定姿势（也是"手臂弹出"）。
改成：沿用物理已有的多 avatar 枚举和距离预算（`physbone_runtime.lua:1719`、`2388–2460`）；每件按 A1 归给最近 avatar；远处队友可降频（隔帧抄旋转、不做 IK）。

### A7 生命周期（#18 #19 #20）

1. avatar 死亡 / 状态机消失 → 停止 IK 和状态读取（只抄旋转，读不到就按 A2 兜底）；尸体不再算物理（冻结在最后姿态）。
2. 换场景（world 变化）、复活（avatar unit 变化）→ 清空独立骨和动作状态缓存，按 A1 重新找件。
3. 物理：时间跳变（dt > 0.25 s）、传送（avatar 根一帧移动 > 2 m）→ 直接重置到动画姿态，不追赶。先核对现有 resync 是否已覆盖，覆盖了就只补缺的。
4. 物理局部回退：某条链出 NaN 或拉长超过 1.5 倍静止长度 → 只把这条链退回动画姿态，下帧重建（核对现有"停链"逻辑，补成可恢复）。

### A8 第一人称

只做核查：第一人称下护甲件是否可见、我们是否还在写手臂/算物理。若不可见仍在算，就在第一人称时停算（判定方法用白名单内已有的相机距离判断）。核查结论写进报告。

## B. 最后：性能优化（A 全部完成并实机通过后才开始）

1. 骨写入变化很小（< 0.05° / 0.1 mm）就不写。
2. 静止链休眠：链根和链本身静止 N 帧后睡，只留唤醒检测。
3. 可选组隔帧交替。
4. A2 回读、A3 状态读取都按需/抽样，量化开销。
5. 远处队友只算必须组、不做 IK。
目标：全开时帧数损失明显小于当前（100→75 fps），近距离观感不变（摆幅前后对比数不变差）。

## E. 第 0 批实机采集结论（2026-11-23 12:18–12:24，飞船内，日志 `tmp/ias-to-patch/e5/state-capture-1224.log`）

- `animation_get_state` 返回 31 个数。**IAS 的层号 = Lua 元组的 1 基下标**：日志"变化层"用的是 0 基，所以 IAS 的 Layer 4 = 日志的 3，Layer 11 = 日志的 10。
