# W21 · IAS 转普通 Mod 手臂离线对齐

W21 把 Milfy 的绑定对齐扩到左右上臂、前臂、两种扭转骨、手掌和 30 根指节。裸手腕口最大拉伸从 W18 的 **11.71 倍降到 1.18 倍**，袖口最大从 **7.80 倍降到 1.86 倍**。肩臂接缝附加间隙低于 0.000005 mm。局部拉伸仍明显，裸臂肘部最高 7.83 倍，躯干侧肩部最高 6.99 倍。

[Milfy-DP8-W21.zip](../../tmp/ias-w21/Milfy-DP8-W21.zip) 可直接用于管理器拖入。CLI 从 W18 的同一份 Milfy 档案解包输入转换，输出原文为 `本体 20 个 Unit，四个选项合计 6 个 Unit。`。ZIP 共 15 个文件，78,909,480 字节，SHA-256 为 `01D3773933A099826E6C07B23475F3152BAA8E981CED289648DED8DEA18F6AED`。`hd2mod import plan` 对 ZIP 退出 0，返回 `"ok": true`，模式 `manifestStrict`，有本体、四个实物选项、两个逻辑默认项，阻断诊断 0。 [W18 输入哈希](../../tmp/ias-w18/archive-input.json) · [最终转换日志](../../tmp/ias-w21/convert-final.log) · [预检输出](../../tmp/ias-w21/import-plan-json.log) · [导入计划](../../tmp/ias-w21/Milfy-DP8-W21.import-plan.json)

## 烘焙实现与物理

- 在 `IasNativeMesh.Convert` 的 IAS 专用路径扩展 W18 的实现。每个选中槽位使用 `avatarBind × inverse(iasBind)`，顶点按折叠前的原调色板权重归一化混合。法线用对应变换的逆转置并归一化。躯干、锁骨、自定义和物理槽位用单位变换，肩部和衣身的交界按原有混权衔接。原有权重折叠、最终蒙皮骨和权重保持一致。没有新增独立骨、姿势资产、Lua 或运行时功能。
- 14 个可见来源 Unit、56 组 LOD、645,112 个顶点的 W21 与无对齐几何对照中，共有 159,032 个位置改变，来自左右臂、两种躯干的肩部混权带和外套。头、髋、腿的位置一致，所有 LOD 的三角形、材质映射、UV 和最终权重一致。Slim 躯干 LOD0 的 10,036 个无选中臂骨输出权重的顶点，位置和法线均相同。其余 1,346 个移动顶点离最近源肩不超过 137.54 mm，其中距肩超过 100 mm 的 242 个顶点最大位移为 6.99 mm。 [LOD 汇总](../../tmp/ias-w21/mesh/mesh-summary.json) · [范围审计](../../tmp/ias-w21/scope.log)
- 与 W18 对照，包内 15 份文件中 13 份逐字节一致，变化集中在本体和外套的 GPU 侧车。三个 `HD2PBX01` 容器各为 49,953、20,480、6,986 字节，容器及 `HD2PBFT1` footer 均逐字节一致。 [逐文件与容器哈希](../../tmp/ias-w21/package-evidence.json)
- W21 的生产差异限于 IAS 几何路径。共用的 `HD2PhysBoneCompat`、`tools/physbone-harness`、`Retarget`、`ApplyExecutor.cs`、`LuaDeploymentService.cs` 和 `PhysBoneContainerEmbedder.cs` 对本地 `master` 零差异。工作树入场时已有 IAS 专用 `IasPhysicsMigration.cs`、`IasDeploymentService.cs` 及若干导入、编译、部署管线改动，与 `master` 存在差异。W21 保留这些基线改动。
