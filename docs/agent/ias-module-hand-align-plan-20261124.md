# W18 IAS 手部离线对齐计划

1. 核对 IAS Unit 和 avatar 的世界绑定矩阵、原始调色板权重及法线空间，对照 master 的手指和手臂重拟合。
2. 在 IAS 标准转换内为左右手掌和各指节预计算绑定差值。按原始权重混合位置和法线，手部以外的影响使用单位变换。默认开启，保留内部关闭参数。保持现有输出骨架、权重、物理链及部署路径。
3. 添加回归测试覆盖矩阵顺序、权重过渡、法线、非手部和关闭开关。用解包样本及原始 Milfy 压缩包核对输入，在沙盒输出可导入产物，记录关节、顶点、握拳相交或翻面以及腕口边的指标。
4. 执行 Debug 构建、全量 .NET 测试、Lua 回归和 `hd2mod import plan`，核对 W18 的文件范围及相对 master 的既有差异，交付报告与产物路径。
