# W18 · IAS 转普通 Mod 手部离线对齐

W18 在 IAS 标准转换时按原始蒙皮权重烘焙左右手掌和 30 根指节的绑定差值。Milfy 的握拳对照里，左右手穿插数从 `1587 → 730` 和 `1579 → 734`，翻面指标从 `924 → 149` 和 `803 → 25`。腕口和袖口仍有明显拉伸，静态绑定姿势的手部穿插数也上升，因此本次几何验收为部分通过。

可拖进管理器的普通 Mod 是 [Milfy-DP8-W18.zip](../../tmp/ias-w18/Milfy-DP8-W18.zip)，绝对路径为 `D:\gitCode\HD2ModManager-ias-module\tmp\ias-w18\Milfy-DP8-W18.zip`。`hd2mod import plan` 退出 `0`，返回 `"ok": true`，模式 `manifestStrict`，阻断诊断为零。ZIP 为 `78,894,334` 字节，SHA-256 为 `582A6CB25D8140946DB450207BA50D343E0B1EF23C2AA7CF66C7B01C0B66977B`。 [预检输出](../../tmp/ias-w18/import-plan.log) · [导入计划](../../tmp/ias-w18/Milfy-DP8-W18.import-plan.json)

## 实现与范围

- 使用 IAS Unit 中的实际世界绑定矩阵，与 `CanonicalAvatarRigReader` 读取的游戏 avatar 世界绑定配对。每根骨的列向量变换为 `avatarBind × inverse(iasBind)`。顶点按解码后的原调色板权重归一化混合，前臂、手腕 twist、自定义链和物理模拟槽位以单位变换参与。法线按各变换的逆转置混合并归一化，方向相消时保留源法线。
- `IasNativeMesh.Convert` 的内部参数 `alignHands` 默认开启。布料袖口上存在手掌和指节权重，因而也参与加权。其余网格使用原有路径。输出使用既有 avatar 绑定、权重折叠和 jiggle 迁移。没有增加 UI、动作、独立骨、Lua 或部署逻辑。
- 已对照 master 的 `Retargeter.Fingers.cs` 和 `Retargeter.ArmRefit.cs`。前者以最小弧和正向运动学在保段长条件下调整方向，后者平滑肩臂平移残差。W18 沿用原权重与非目标骨单位变换的混合原则，直接使用现有 `Mat4` 求逆和变换。两套 VPK 重拟合的输入及目标与 IAS 的逐骨绑定差值不同，原文件无需改动。
- 实样 A/B 共比了 14 个可见来源 Unit、56 组 LOD、645,112 个顶点。78,552 个位置变化落在左右臂和穿外套的两种体型，其他 Unit 位置一致。三角形、UV、材质映射及最终蒙皮权重逐项相同。与 W17 产物相比，15 个文件中 13 个逐字节一致，仅本体和穿外套的两个 GPU 侧车变化。三个 `HD2PBX01` 物理容器整体逐字节一致。
- W18 的生产改动限于 `IasNativeMesh.cs` 和新增的 `IasHandBindAlignment.cs`。共用物理/Lua/部署路径对 master 零差异，包括 `HD2PhysBoneCompat`、`tools/physbone-harness`、`Retarget`、`ApplyExecutor.cs`、`LuaDeploymentService.cs` 和 `PhysBoneContainerEmbedder.cs`。整个工作树仍有 master 未包含的既有 IAS 专用 `IasPhysicsMigration.cs` 和 `IasDeploymentService.cs`。如零差异要求覆盖这些 IAS 专用文件，也仍有待决项。 [LOD 对照](../../tmp/ias-w18/mesh/mesh-summary.json) · [容器哈希](../../tmp/ias-w18/package-evidence.json)

## 握拳与腕口

离线握拳使用真实 avatar 世界绑定，从每侧掌面和原指链推导弯曲轴，再沿父链叠加关节角。四指三节分别弯 `35° / 45° / 25°`，拇指弯 `20° / 35° / 20°`。对关闭和默认开启的同拓扑网格使用相同 avatar 姿势和相同输出蒙皮权重。模型仅覆盖一个合成握拳姿势和各 Unit 内部的相交，未包含游戏动画或手与另一件装备的跨 Unit 相交。

穿插计数统计严格穿过三角形内部的非相邻面片对，排除了共面接触、端点接触和源坐标焊接后的共顶点面。翻面指标按原始绕序校准，以几何面法线与平均顶点法线的点积低于阈值 `-0.05` 计数。Stocky 的下列计数与 Slim 相同。 [完整离线指标](../../tmp/ias-w18/hand-metrics.json) · [左手线框](../../tmp/ias-w18/LeftArm-Slim-05f531d8a964ca8d-l.png) · [右手线框](../../tmp/ias-w18/RightArm-Slim-de393af45904722c-r.png)

## 待决

- 原始腕口权重下，完整绑定差值需要在短过渡带内吸收约 140 mm 的手腕偏移。若要把当前包推进到腕口无明显拉伸，需要派活方决定可否放宽约束，例如允许 IAS 腕口局部重分配或允许前臂末端参与，或者降低腕口附近绑定对齐幅度。握拳残留穿插、静态姿势穿插增加和右袖口穿插也需要实机复核。当前 ZIP 适合测试，腕口无拉伸条件未达成。
- 如果要求整个工作树中的 IAS 专用物理和部署实现也与 master 零差异，需要对既有模块改动单独决策。解决方案级构建仍需在能运行对应 MSBuild 子任务的环境中复核。
